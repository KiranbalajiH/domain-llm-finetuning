End-to-End Engineering Topology

Fine-Tuning & Serving Pipeline Architecture

How the QLoRA pipeline processes finance data, quantizes weights into 4-bit NormalFloat precision, optimizes low-rank adapters, and serves dual inference.

1

Data Ingestion & Split

650 domain examples across SOX 404, SEC 10-K, and Cloud FinOps formatted as Instruction JSONL with a stratified 90% train / 10% test split.

2

QLoRA Training Loop

BitsAndBytes 4-bit NF4 double quantization with Hugging Face TRL SFTTrainer. LoRA rank $r=16$, $\alpha=32$ targeting all linear projection layers.

3

Dual-Dispatch Serving

FastAPI backend loads the 134MB adapter checkpoint dynamically, concurrently serving base and adapter inference with sub-700ms latency.
